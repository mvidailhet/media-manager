# Allow moving media files to Trash

The app may move selected media files to the system Trash from explicit user actions in **Video Detail Panel**, **Batch Metadata Edit**, and **Scan Root** review workflows. This supersedes the v1 read-only media-file boundary because removing unwanted local files is part of organizing a local **Catalog**, but the operation is limited to Trash moves behind confirmation rather than permanent deletion, renaming, or arbitrary file moves.
